Оплата сервиса

Страницы /partner-payment/recharge и /partner-payment/history · право servicePayments.view · обычная CRM-страница (STRICT_CURRENT).
Это не кошелёк. Абонплата KidsCRM (2 500 ₽ / 30 дней) пишется в partner_payments + partner_accesses. Кошелёк школы — partner-wallet.

1) Доступ

  • Маршруты в группе auth + 2fa + can:servicePayments.view.
  • Право в группе permissions partner, не в базовой роли admin (config/role_base_permissions.php закомментирован).
  • Без права — 403 (JSON и web). Гость — 302 на логин / 401 JSON.

2) Изоляция по партнёру

ПоверхностьЧто ограничено
GET /partner-payment/recharge Hidden partner_id = current (PartnerContext), не хардкод value="1".
GET /partner-payment/history, GET /partner-payment/data DataTables: WHERE partner_payments.partner_id = current. Чужие строки не в data / recordsTotal.
POST payment/service/yookassa CreatePartnerServicePaymentRequest: partner_id обязан совпасть с current — иначе 422 / 302 errors.partner_id «Нельзя оплатить сервис за другую школу.» (до ЮKassa запись не создаётся). Запись — partner_id из PartnerContext.
Период доступа при создании платежа считает latestActiveAccessEndDateForPartner: последний активный partner_accesses.end_date этой школы через partner_payments.partner_id. Не PartnerAccess::max('end_date') по всей таблице (иначе новая школа получала бы период в хвосте Истока).

3) Ошибки

  • Валидация в CreatePartnerServicePaymentRequest (rules / attributes / messages).
  • Native POST: 302 назад + session errors[field] под полями (data-error-for="partner_id", amount, days, description).
  • AJAX / postJson: 422, тексты из errors[field].
