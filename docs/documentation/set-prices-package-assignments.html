Право setPrices.packageAssignments.view

Файл: /docs/documentation/set-prices-package-assignments.html. CRM: вкладка /admin/lesson-packages/assignments; консоль: блок «Назначенные абонементы» на /cabinet.
С 2026‑08 доступ к назначениям абонементов отделён от общего lessonPackages.view. Нужны оба права: раздел «Расписание школы / Абонементы» и это право на вкладку/CRUD/блок консоли.

1) Право

ПолеЗначение
ИмяsetPrices.packageAssignments.view
Описание (сидер)Установка цен / Консоль: назначение абонементов
Группа матрицыsetPrices («Установка цен») — settings-permission-groups
is_visible0 (невидимое): у admin партнёра в матрице может не отображаться; у superadmin — видно
GateAuthServiceProvider → setPrices.packageAssignments.view
SeederPermissionSeeder (sort_order: 22)
Миграция2026_08_03_221000_add_set_prices_package_assignments_view_permission.php — только создаёт право, никому не выдаёт
Базовые ролиВ config/role_base_permissions.php для user / admin / trainer не входит (строка закомментирована). Существующих партнёров миграция не трогает.
После выката на уже работающих школах право нужно выдать вручную (superadmin / SQL в permission_role), иначе вкладка «Назначение абонементов» и блок на консоли пропадут у всех, у кого не было явной выдачи. Новым партнёрам по умолчанию тоже не выдаётся.

2) Что закрывает

ПоверхностьПоведение без праваС правом (+ lessonPackages.view где нужно)

* POST …/manual-paid дополнительно требует lessonPackages.manualPaid.manage.

4) Endpoint'ы (кратко)

Полный контракт UI/API — lesson-packages §assignments-tab. Группа маршрутов: can:lessonPackages.view → внутри can:setPrices.packageAssignments.view (кроме users-search).
  • Страница / DataTable / columns / logs / teams-for-user / store / show / update / destroy / public-pay-link — оба права.
  • Create-форма — classic POST → 302 на вкладку (не пустой 200).
  • Модалка «Изменить» — AJAX fetch (PUT/DELETE/GET show) → JSON 200/422.
