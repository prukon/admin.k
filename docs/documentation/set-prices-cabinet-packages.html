Права setPrices.cabinetPackages.*

Файл: /docs/documentation/set-prices-cabinet-packages.html. Анонс: /doc. Консоль: /cabinet. Вкладка назначений в админке — отдельно: setPrices.packageAssignments.view.
С 2026‑08 отображение абонементов на консоли не зависит от setPrices.packageAssignments.view. Для каждого типа — своё скрытое право группы setPrices. Никому не выдаётся автоматически.

1) Права

ИмяОписаниеschedule_typeГде на консоли
setPrices.cabinetPackages.fixed.view Консоль: фиксированный абонемент fixed Карточка в блоке «Назначенные абонементы» (ULP)
setPrices.cabinetPackages.flexible.view Консоль: гибкий абонемент flexible Карточка ULP
setPrices.cabinetPackages.single.view Консоль: разовое занятие no_schedule Карточка ULP
setPrices.cabinetPackages.postpay.view Консоль: постоплата postpay Месяцы в блоке сезонов (users_prices), не ULP

После выката права нужно выдать вручную (superadmin / матрица). Без них карточки ULP и месяцы постоплаты на /cabinet скрыты, даже если записи в БД есть. POST /payment эти права не проверяют — кнопка «Оплатить» по-прежнему требует paying.classes.

2) Что закрывает

ПоверхностьБез соответствующего праваС правом
Карточки ULP (fixed / flexible / single) Тип отфильтрован в DashboardController; блок скрыт, если не осталось ни одной карточки Карточка видна при fee_amount_cents > 0
Месяцы постоплаты в сезонах Строка не попадает в userPrice / JSON getUserDetails Месяц в сезонах; блок сезонов показывается и без cabinetSeasons.view
Обычные (не postpay) месяцы сезонов Как раньше: нужны setPrices.cabinetSeasons.view Без изменений
Селект «Выбор группы» — Сезоны / postpay или есть видимые карточки ULP (и 2+ группы)
Семейный кабинет (смена ребёнка) Без права типа карточки активного ребёнка не видны Данные активного ученика; право проверяется у залогиненного (роль user общая у братьев)
