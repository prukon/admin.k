Сессия 30 дней, «Запомнить меня», страница 403

Файл: /docs/documentation/session-lifetime.html · анонс: /doc
Кратко. Idle-сессия SESSION_LIFETIME=43200 (30 суток), драйвер по-прежнему file. На /login галка «Запомнить меня» включена с первого показа. HTML 403 для гостя — layouts.app, не кабинетный admin2 (иначе auth()->user()->role на null превращал 403 в 500). Redis/БД для сессий этот инкремент не вводит.

1) Срок сессии

  • config/session.php: lifetime = (int) env('SESSION_LIFETIME', 43200).
  • 43200 минут = 30 суток бездействия. Закрытие браузера сессию не убивает (expire_on_close = false).
  • Пока открыта вкладка кабинета, POST /presence/ping раз в минуту сдвигает mtime файла сессии.
  • Драйвер SESSION_DRIVER=file, каталог storage/framework/sessions. Сборщик лотереи [2, 100] без изменений.

2) «Запомнить меня»

  • Форма resources/views/auth/login.blade.php, чекбокс #remember / name="remember".
  • Первый GET /login — атрибут checked (без old()).
  • После редиректа с withInput() (session()->hasOldInput()): галка как в POST. Сняли и ошиблись в пароле — остаётся снятой. old('remember') без hasOldInput() снова включил бы галку.
  • Сервер: AuthenticatesUsers / $request->boolean('remember'). Поля нет — remember-cookie не ставится. Поле есть — cookie recaller ~400 дней (SessionGuard rememberDuration 576000 минут).

3) Страница 403

  • resources/views/errors/403.blade.php: @extends(auth()->check() ? 'layouts.admin2' : 'layouts.app').
  • Гость: лейаут логина, кнопка «Войти» на route('login'), noindex, nofollow через @push('meta').
  • Залогиненный: кабинетный лейаут, кнопка «На главную» на /.
  • Сайдбар admin2: auth()->user()?->role?->label (не optional(auth()->user()->role) — тот всё равно читает ->role у null).
  • Типичный продовый каскад до фикса: протухшая сессия → POST /broadcasting/auth без пользователя → AccessDeniedHttpException 403 → рендер HTML 403 через admin2 → ErrorException «Attempt to read property "role" on null» в пульт как 500. HTTP 403 по-прежнему не пишется в строку 500 пульта (Handler режет 4xx).
