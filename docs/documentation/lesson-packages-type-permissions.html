Права lessonPackages.type.*

Файл: /docs/documentation/lesson-packages-type-permissions.html. Анонс — /doc#lesson-packages-type-permissions-index; постоплата отдельно — lesson-packages-type-postpay; шаблоны — lesson-packages; матрица — settings-permission-groups; базовые роли — partners-permissions.
С 2026‑09 выбор schedule_type шаблона абонемента закрыт скрытыми правами на каждый тип, по тому же принципу, что и lessonPackages.type.postpay (2026‑08). lessonPackages.view открывает раздел; без type-права нельзя создать шаблон этого типа, сменить тип на него и назначить такой пакет в «Установка цен» / правилах уведомлений. Уже созданные шаблоны и уже назначенные месяцы продолжают работать.

После выката три новых права нужно выдать вручную (superadmin в матрице школы). Пока права нет, option типа скрыт и новый выбор недоступен. Существующие шаблоны и уже назначенные users_prices.lesson_package_id / team_prices не удаляются. Права консоли setPrices.cabinetPackages.*.view — другой контур (карточки на /cabinet), этими type-правами не выдаются и не снимаются.

2) Что закрывает

ПоверхностьБез права на типС правом (+ родительские права раздела)
Кнопка «Добавить абонемент» Скрыта, если нет ни одного lessonPackages.type.* (userCanSelectAny) Кнопка видна
Шаблоны: option типа в create / edit / фильтре (packages.blade.php, дубль в «Справочниках») Option скрыт (@can). При открытии уже существующего шаблона этого типа в edit option добавляется JS-ом (LABELS), чтобы значение не «терялось» Option виден
POST/PUT …/lesson-packages с этим schedule_type 422 на schedule_type («Недостаточно прав для выбора типа «…»»). Исключение: update уже существующего шаблона без смены типа — разрешён AJAX → 200 JSON; non-AJAX → 302 на index
DataTables фильтр по типу (в т.ч. crafted query) Пустой результат Строки этого типа. Список без фильтра по-прежнему показывает все шаблоны партнёра
Select абонемента на вкладке «Назначение абонементов» (ULP) (LessonPackageController::assignments → packagesList) Пакеты типа не в списке (restrictQueryToAllowedTypes, без keepIds) Пакеты типа в списке. Postpay при праве postpay тоже может попасть в select — store всё равно доменное 422
Фильтр типа на вкладке «Назначение абонементов» (ULP) (filter_schedule_type) Option скрыт; crafted query без права — пустой результат. Postpay в этом фильтре нет даже с правом (ASSIGNMENT_SCHEDULE_TYPES: только fixed / flexible / no_schedule) Option виден для fixed / flexible / no_schedule
Store ULP с пакетом этого типа 422 на lesson_package_id («Недостаточно прав для выбора абонемента типа «…»»). Postpay — отдельное доменное 422 даже с правом postpay AJAX → 200 JSON; non-AJAX create → 302 на вкладку (кроме postpay)
«Установка цен»: каталог lessonPackages (monthly / getTeamPrice / year) Шаблоны типа скрыты, кроме уже назначенных в team_prices / users_prices Все шаблоны этого типа у партнёра
setTeamPrice, setPriceAllUsers, setPriceAllTeams, saveUserYearPrices 422 на поле пакета при новом выборе: lesson_package_id, usersPrice.{i}.lesson_package_id, teamsData.{i}.lesson_package_id, prices.{i}.lesson_package_id («Недостаточно прав для выбора абонемента типа «…»»). Повторная отправка того же уже назначенного id — разрешена Ожидаемые 200 / 302
Пролонгация месяца Пропуск с type_denied / для postpay postpay_denied. Текст пропуска — denyPackageMessage («Недостаточно прав для выбора абонемента типа «…»»). Общий ярлык REASON_LABELS[type_denied] — «Недостаточно прав для выбора этого типа абонемента.» Копия шаблона на M+1
Уведомления об оплате: чекбоксы типов HTML-чекбокс скрыт (@can). no_schedule в конструкторе нет (PaymentNotificationRule::ALLOWED_SCHEDULE_TYPES). Store/update с новым типом без права → 422 на schedule_types. Типы, уже стоящие на правиле, можно оставить при update. Мутации всегда JSON (201/200/422) Чекбокс в HTML виден. JS как в коде: openCreate() → setScheduleTypes(['fixed', 'flexible']) и ensureScheduleTypeCheckbox может подставить скрытые чекбоксы; backend всё равно 422. Edit подставляет типы, уже стоящие на правиле
Не закрывает этими правами (нужны другие права + уже назначенный пакет): журнал, календарь школы, оплата с консоли, показ карточек на /cabinet (setPrices.cabinetPackages.*.view). Список шаблонов без фильтра по типу показывает все шаблоны партнёра (в т.ч. типы без права) — закрыт только выбор типа и новое назначение.
Create-модалка шаблона при открытии ставит schedule_type = 'fixed' (shown.bs.modal), даже если option fixed скрыт @can. Это текущий JS, не отдельный backend-дефолт: без права fixed store → 422 на schedule_type.
