Кратко. Личные диалоги 1-на-1 внутри текущей школы плюс одна «Служба поддержки» вместо суперадмина (анонс). Текст без вложений. Повторный клик по контакту открывает тот же тред, даже после 0/1 живого (анонс идентичности). Пункт «Чат» в сайдбаре, бейдж badge-info — число непрочитанных (скрыт при 0). Онлайн — зелёная точка (в списке диалогов красной нет), галочки только у исходящего, карточка собеседника из шапки открытого диалога. Под названием — участники группы или «онлайн» / «был(а) в сети…» (анонс подзаголовка), не в списке слева. Неотправленный текст — черновик на сервере, в списке превью «Черновик: …» (анонс). Можно создать групповой чат: кнопка «Создать группу», название, затем выбор участников (анонс групп). Состав открытой группы — из шапки: добавить / удалить (admin/superadmin), покинуть (любой) (анонс состава). Учебная группа сразу получает свой чат (threads.team_id, анонс). В списке слева группа показывает имя чата, не «Диалог» и не ФИО участника (анонс имени в списке). Фильтр контактов по учебной группе — селект в модалке (анонс), не сам групповой чат. На планшете и телефоне (с 992px) — нижняя панель как в Telegram (анонс): «Личные сообщения» без групп, «Чаты» — только группы (анонс сплита). Стили и JS страницы — Vite только на /chat. Realtime — тот же Reverb, что у колокольчика, без HTTP-опроса inbox / unread / истории. Если сокет не connected, новые сообщения и бейдж не обновляются, пока процесс не поднимут (оверлей Reverb у superadmin). При reconnect — один refresh.
Не путать с колокольчиком in-app уведомлений (in-app-notifications) и с email «Установка цен → Уведомления». Не путать черновик сообщения с черновиком ЗП тренеров (схема Канзас). Кнопка «Создать группу» создаёт ручной групповой чат, это не учебная группа и не селект фильтра контактов. Чаты учебных групп создаются сами (threads.team_id, анонс). Селект групп в контактах и в визарде участников — фильтр учеников школы, не список групповых переписок (анонс). Вкладка «Чаты» на узком экране — кнопка «Создать группу» и список групповых чатов (#groupThreads, is_group). Вкладка «Личные сообщения» — только 1-на-1 (!is_group), без групп. Десктоп слева по-прежнему общий список (анонс сплита). Вкладка «Аккаунт» — карточка в чате, не /account-settings/user/edit. Leftover личка в списке может называться «Диалог» (peer_id: null) — это тот же тред, не новая переписка (анонс идентичности). Учётка superadmin в users не переименовывается: в чате это «Служба поддержки», не ФИО и не роль «Суперадмин» (анонс).

2) Как это выглядит

  1. Сайдбар: «Чат» (иконка конверта). Бейдж js-chat-unread-count с классом badge badge-info (не красный), скрыт при 0, иначе точное число непрочитанных. Живое обновление: сокет inbox.bump / thread.read, без HTTP-опроса. Если сокет не connected, бейдж и список не подтягиваются таймером. При reconnect Echo один раз вызывает KidsCrmChatRefreshInbox (на странице чата) или GET /chat/api/unread (на остальных). Если открыт тот же диалог, бейдж не вспыхивает (из unread_total вычитается unread этого треда).
  2. Слева — список диалогов (непрочитанные выше, затем по времени). Поиск по заголовку (ФИО лички / имя группы), превью и черновику. Заголовок личного диалога, шапка и GET /chat/api/threads/{id} — users.lastname + users.name (если фамилии нет — только имя). Исключение: канонический superadmin всегда «Служба поддержки» (§2.6 / анонс), не ФИО из учётки. Групповой чат в списке слева и в шапке — threads.subject (имя чата), не «Диалог» и не ФИО первого участника; пустое имя — «Группа» (threadListTitle / ChatService::titleForViewer, анонс). .chat-li-title / .chat-li-middle прижаты влево (text-align: left), не по центру — и десктоп, и моб (правило вне @media (max-width: 991.98px); глобальный body.sidebar-mini иначе центрирует текст). В шапке то же: .chat-header-text, #threadTitle, .chat-header-subtitle. Клиент при открытии диалога перезаписывает title в списке слева из этого ответа: у личного — те же колонки собеседника (ChatService::PEER_USER_COLUMNS, с lastname), у группы — снова имя чата, не ФИО участника. Справа сверху — время последнего сообщения (сегодня ЧЧ:ММ, иначе дата). Под временем, справа внизу — каунтер непрочитанных (.chat-li-unread, фон #f3a12b); при 0 не показываем. Если последнее сообщение исходящее: одна серая галочка слева от времени, пока собеседник не прочитал, две зелёные — после прочтения (как в пузыре сообщения). Если собеседник онлайн (last_seen_at не старше 2 минут) — зелёная точка справа снизу на аватарке списка. Офлайн в списке точку не рисуем. Если у текущего пользователя есть неотправленный текст — превью Черновик: … вместо последнего сообщения (.chat-li-preview.is-draft, цвет #f3a12b), время справа остаётся last_message_time. Черновик свой, на сервере; собеседник его не видит. Клик по строке открывает диалог (openThread), подставляет черновик в поле и сразу ставит фокус в #msgInput (после setComposerEnabled(true)). В шапке открытого диалога под названием (#threadSubtitle, JSON header_subtitle) — не в списке слева: у группы число участников («N участник/участника/участников», members_total); у лички статус собеседника: «онлайн» (окно 120 секунд), «был(а) в сети 2 минуты назад» / «… 5 минут назад» (2–5 минут, не «1 минуту»), дальше «был(а) в сети в 16:50 18 августа 2028» (H:i j F Y, peer_presence_label); никогда не пинговал — подпись скрыта. Подробнее — §2.1.1 / анонс, онлайн — §2.1, черновик — §2.2 / анонс.
  3. «Контакты» открывает модалку контактов текущей школы (стандартная ширина Bootstrap, список до 60vh / 520px со скроллом) плюс первая строка «Служба поддержки» при «Все группы» / «Без группы» (§2.6 / анонс; в фильтре конкретной учебной группы этой строки нет). Справа снизу аватарки: зелёная точка если онлайн, красная если офлайн (в том числе если человек ещё ни разу не пинговал после появления last_seen_at). После аватарки три колонки: слева фамилия и имя (users.lastname + users.name, JSON name; без фамилии — только имя; у поддержки — подпись, не ФИО учётки), под ним ФИО родителя серым меньшим шрифтом (parent_full_name, .contact-parent) — только если строка непустая; имя и родитель прижаты влево (text-align: left у .contact-main / .contact-name / .contact-parent), иначе body.sidebar-mini (text-align: -webkit-center) центрирует и на вкладке «Контакты», и в модалке участников; по центру на одной линии с именем — группы ученика (team_title, .contact-team); справа — роль (.contact-role, у поддержки та же подпись, не «Суперадмин» и не role_name). Пустую строку родителя не показываем. Поиск ?q= — по фамилии и имени ученика, email, фамилии и имени родителя (parents.lastname / parents.firstname); у поддержки — только по «Служба поддержки», не по ФИО/email учётки. Отчество родителя и soft-deleted карточка в поиске не участвуют. Фильтр по учебной группе — нативный селект #contactsTeamFilter над поиском (не Select2, не multi, не групповой чат): «Все группы», «Без группы», группы текущей школы. ?team_id= вместе с ?q=: пусто — все контакты как раньше; none — без групп в team_user (админы, тренеры, ученики без группы); id группы — только ученики этой группы (системная роль user, не тренеры). При открытии модалки селект сбрасывается вместе с поиском. Ошибки фильтра — #contactsTeamError (errors.team_id), поиска — #contactsError.
  4. «Создать группу» рядом с «Контакты» на десктопе (#openCreateGroupBtn, d-none d-lg-inline-block) и на вкладке «Чаты» (#openCreateGroupMobileBtn). Сначала модалка названия (#createGroupNameModal), затем участники (#createGroupMembersModal). Обе стандартной ширины Bootstrap. На узком экране шаг 2 ограничен max-height: calc(100dvh - 1rem): список скроллится, «Отмена» / «Создать» остаются в зоне экрана (не fullscreen). Подробно — §2.4 / анонс.
  5. Клик по контакту открывает существующий 1-на-1 или создаёт новый. Повторный клик по тому же человеку не плодит диалоги.
  6. Справа — переписка. Свои пузыри (.msg-mine) прижаты вправо, входящие (.msg-other) влево (не по центру). Время/дата в .msg-meta на одной строке (white-space: nowrap), даже у сообщения из 1 символа. Композер disabled, пока не выбран диалог. У своих сообщений одна серая галочка, пока собеседник не прочитал, и две зелёные — после прочтения (сокет thread.read; без HTTP-опроса is_read). Под названием в шапке — #threadSubtitle (§2.1.1: участники группы / «онлайн» / «был(а) в сети…»). Клик по аватарке или имени в шапке открытого личного диалога открывает модалку карточки собеседника (стандартная ширина Bootstrap): аватар, ФИО (lastname+name), телефон ученика (tel:), ФИО и телефон родителя, последний онлайн («онлайн» / дата-время / «-»), группы. Пустые поля в карточке — «-». Клик по шапке группы открывает модалку состава (#groupCardModal, §2.4). Ошибки — под полями (#msgBodyError, в модалке контактов #contactsError, в карточке #peerCardError, в карточке группы #groupCardError).
  7. История вверх: скролл (в т.ч. свайп) внутри #messagesBox. Подгрузка GET .../messages?before_id= начинается заранее (maybeLoadOlder, порог ≈ 1.5 экрана, минимум 480px), а не у самого верха. После порции — ещё раз, пока запас не набран. Страница кабинета не скроллится.
  8. Планшет и телефон (max-width 991.98px, Bootstrap lg): body.chat-immersive только на chat.index — шапка кабинета (.main-header: гамбургер, колокольчик, Выйти) видна, скрыт .main-footer, сайдбар — оверлей по гамбургеру. Высота области — остаток 100dvh под шапкой. Внизу #chatMobileNav как в Telegram: Контакты (fa-solid fa-address-book), Личные сообщения (fa-solid fa-comment, бейдж js-chat-private-unread-count — только 1-на-1), Чаты (fa-solid fa-comments, кнопка «Создать группу», список групп, бейдж js-chat-group-unread-count — только группы), Аккаунт (fa-solid fa-user). Иконки из локального FA 6 (includes.fontawesome, не CDN Kit). Кнопка «Контакты» в поиске списка — d-none d-lg-inline-block (только десктоп), рядом «Создать группу» с тем же классом. Открытый диалог: #chatApp.is-dialog-open, стрелка #chatMobileBack (fa-arrow-left), нижняя панель на время диалога скрыта. Контакты на узком экране — вкладка: #contactsMount переносится из #contactsModalBody в #chatPaneContacts. Аккаунт — карточка себя в #accountCardBody через GET /chat/api/users/{me} и тот же renderPeerCard, ошибка #accountCardError. Не переход на учётку кабинета. Подробно — §2.3 / §2.3.1 / анонс панели / анонс сплита.

2.1) Онлайн, галочки исходящего, ФИО родителя, карточка

Анонс на главной: /doc#chat-presence-index.

  1. Онлайн. users.last_seen_at, окно 120 секунд (UserPresence::ONLINE_WITHIN_SECONDS, сравнение gte: ровно 2 минуты ещё онлайн). Никогда не пинговал — офлайн. POST /presence/ping (presence.ping): группа auth+2fa, без can:messages.view. JSON {ok: true} и у AJAX, и у нативного POST (heartbeat, не 302 на раздел). Throttle записи в БД — 30 секунд. Клиент: includes/in_app_notifications/echo.blade.php, ping() при загрузке и setInterval(ping, 60000). Скрипт не содержит route('chat.index'), чтобы HTML dashboard без права чата не тащил URL /chat.
  2. Список диалогов. Заголовок личного — lastname+name (без фамилии — только имя). Группа — threads.subject (имя чата), не «Диалог»; пустое — «Группа». Имя в .chat-li-title слева (text-align: left), не по центру. Время справа сверху — last_message_time (сегодня часы:минуты, иначе ДД.ММ.ГГ), поле last_seen_at в payload списка нет. Каунтер непрочитанных — .chat-li-unread справа внизу под временем, цвет #f3a12b; при 0 не рисуем. peer_is_online → класс chat-online-dot; офлайн — без точки и без is-offline. Галочки (ticksHtml) только если last_message_is_mine: непрочитано — checks-sent (одна серая), прочитано — checks-read + check-second. Входящее: last_message_is_read = null, галочек нет. Клик по строке — openThread, не карточка; после включения композера в #msgInput подставляется свой draft_body и ставится фокус. Под названием в шапке открытого личного диалога (#threadSubtitle, JSON header_subtitle / peer_presence_label на GET /chat/api/threads/{id}, не в inbox): «онлайн» в окне 120 секунд; 2–5 минут — «был(а) в сети N минуты/минут назад» (121 с → «2 минуты», не «1 минуту»); больше 5 минут — «был(а) в сети в ЧЧ:ММ D месяца YYYY» (пример: «был(а) в сети в 16:50 18 августа 2028»); last_seen_at пустой — подпись скрыта. Карточка шапки по-прежнему «онлайн» / d.m.Y H:i / «-». Анонс подзаголовка: /doc#chat-header-subtitle-index, подробно — §2.1.1. Неотправленный текст: PATCH /chat/api/threads/{id}/draft (поле body, debounce 500 мс на клиенте, сразу при уходе из диалога). В списке при непустом своём draft_body — превью Черновик: … (.chat-li-preview.is-draft, #f3a12b), не последнее сообщение. Собеседник в JSON списка и show видит только свой черновик (чужой не отдаём). Успешная отправка обнуляет черновик отправителя. InboxBump после send несёт draft_body: '' только отправителю (у собеседника ключ не ставим, чтобы не затереть его кэш). Анонс: /doc#chat-draft-index, подробно — §2.2.
  3. Контакты. is_online → contact-online-dot is-online / is-offline (ни разу не seen = красная). Три колонки после аватарки, выравнивание по верху: слева .contact-main (имя и под ним .contact-parent, text-align: left против body.sidebar-mini), по центру .contact-team (team_title) на одной линии с именем, справа .contact-role. JSON name — фамилия и имя ученика. Поиск ?q= по users.lastname / users.name / email / parents.lastname / parents.firstname (soft-deleted родитель не матчится). Фильтр #contactsTeamFilter / ?team_id=: пусто — все; none — без team_user; id — только ученики группы. Ошибки team_id — #contactsTeamError. Строка .contact-parent только при непустом parent_full_name; пустую и пробелы не показываем и не рисуем «-». В JSON контактов нет phone / parent_phone / last_seen_at. Soft-deleted родитель → пустое ФИО. Клик по строке — startDialog.
  4. Карточка шапки. #threadPeerHit с классом is-idle, пока диалог не открыт; openPeerCard сразу выходит, если нет currentPeerId. GET /chat/api/users/{user}: full_name, phone, parent_full_name, parent_phone, is_online, last_seen_at, last_seen_label («онлайн» / d.m.Y H:i / «-»), team_title. В UI пустое — «-», телефоны с tel:. Своя школа, в том числе отключённый и сам себе — 200; чужой партнёр — 403. Модалка #peerCardModal стандартной ширины, ошибки в #peerCardError.
  5. Перерисовка. InboxBump отдаёт те же флаги списка, что HTTP inbox. markListOutgoingRead меняет галочки, только если последнее сообщение исходящее.

2.1.1) Подзаголовок шапки открытого диалога

Анонс на главной: /doc#chat-header-subtitle-index. Строка под #threadTitle в открытом диалоге, не в списке слева и не в карточке человека.

  1. Разметка. #threadSubtitle (.chat-header-subtitle) внутри .chat-header-text, сразу под названием. Пока диалог не выбран — пусто и style="display:none;". Имя и подпись — text-align: left (.chat-header-text, #threadTitle, .chat-header-subtitle), иначе body.sidebar-mini центрирует. Клиент setThreadSubtitle: textContent (HTML из payload не исполняется), пустая строка → display:none.
  2. Группа. header_subtitle = membersCountLabel(members_total) («1 участник», «2 участника», «5 участников», «11 участников», «21 участник»). members_total — живые видимые (visibleGroupMembersCount): soft-delete не входит, лишний superadmin не входит. peer_presence_label у группы пустое: онлайн участников не подставляем. После add/kick клиент берёт счётчик из JSON состава (setThreadSubtitle(membersCountLabel(thread.members_total))), не leftover предыдущего диалога. #groupCardCount в модалке состава — то же склонение, отдельный элемент.
  3. Личка. header_subtitle = peer_presence_label = UserPresence::dialogStatusLabel. Окно «онлайн» — 120 секунд (ONLINE_WITHIN_SECONDS, gte). 121 с → «был(а) в сети 2 минуты назад» (не «1 минуту»). 2–4 мин — «минуты», 5 — «минут».   8. Backfill. Миграция 2026_08_19_140000_add_team_id_to_threads_table (в т.ч. для групп, созданных через factory).

2.6) Служба поддержки вместо суперадмина

Анонс: /doc#chat-support-identity-index. Учётка superadmin в БД не переименовывается. В чате любой зритель (включая самого суперадмина) видит подпись Служба поддержки, не ФИО и не роль «Суперадмин».

  1. Кто это. Канонический пользователь — активный (is_enabled=1) superadmin с минимальным users.id (ChatSupportIdentity::canonicalUserId). Остальные superadmin в контакты, состав группы и новые чаты учебных групп не попадают. Личка с неканоническим superadmin скрыта из inbox. POST лички с id лишнего superadmin нормализуется на канонического (тот же тред, 422 чужой школы не ставим).
  2. Где подпись. Контакты и пикер участников (name, role_label), заголовок лички / titleForViewer / inbox.bump, состав группы (full_name, role_label), карточка GET /chat/api/users/{id} (телефон, родитель, группы пустые). В JSON role_name остаётся superadmin (колонка роли на экране берёт role_label, JS: role_label || role_name в контактах, пикере «Создать группу» и «Добавить участников»). Нативный POST лички/группы без X-Requested-With — 302 на /chat, не сырой JSON. AJAX — 201/200 JSON; extra+canonical в одном user_ids — 422 под errors.user_ids (повторы после нормализации не схлопываем).
  3. Контакты без нагрузки. Запрос школы как раньше: partner_id текущей школы, без OR по всем superadmin. Superadmin из этого запроса исключаются (role_id <>). Канонический ряд подмешивается отдельно: один ORDER BY id LIMIT 1 / PK, в начало списка. Поиск ?q= — только по строке «Служба поддержки», не по ФИО/email учётки. Фильтр конкретной учебной группы канонического не показывает; «Все группы» и «Без группы» (none) — показывает, если его ещё нет в exclude_thread_id. Себя каноническому в контакты не кладём.
  4. Карточка. ChatUserShowRequest: канонический доступен при partner_id = null; лишний superadmin чужому зрителю — 403; свою карточку (вкладка «Аккаунт») можно открыть — тоже «Служба поддержки», не ФИО. Карточка канонического маскирует телефон, родителя и группы.

2.7) Идентичность личного диалога

Анонс: /doc#chat-private-thread-identity-index. Повторный клик по контакту не создаёт второй тред 1-на-1. Группы по составу не склеиваются (§2.4). Включение учётки само личку не возвращает (§2.5).

  2. Поиск. ChatService::findPrivateThread: JOIN пары включая trashed, whereNotExists любого другого user_id, threads.is_group=0. Не has(participants, 2). Живых может быть 2, 1 или 0. Группа из двоих, тред на троих без флага, пустой чат с threads.team_id — не личка.

4) Данные и код

  1. Таблицы пакета messenger: threads, messages, participants (soft deletes). threads.is_group — групповой чат (default 0); название группы — threads.subject. threads.team_id — чат учебной группы (nullable unique); ручные группы без этой колонки. Если колонки ещё нет или флаг 0, тред с тремя и более участниками всё равно группа: в списке имя из subject, peer_id: null, дедуп 1-на-1 его не подменяет. Своя колонка participants.draft_body (nullable text, до 5000 символов) — черновик текущего участника, собеседник её не читает. participants.unread_count — денормализованный счётчик непрочитанных (бейдж сайдбара = SUM, не COUNT по messages). threads.last_message_id — превью списка без скана latestOfMany. Индексы: messages (thread_id, id), messages (thread_id, created_at), participants (user_id, thread_id), UNIQUE participants (thread_id, user_id) (participants_thread_user_unique; soft-deleted строка тоже занимает слот — повторный вход через restoreOrCreateParticipant / restoreParticipantIfTrashed, не второй INSERT), threads.last_message_id.
