Деньги: хранение в копейках

Канон проекта (2026‑08). Класс: App\Support\Money. Миграция: 2026_08_06_180000_convert_money_columns_to_cents.php (backfill ROUND(rub × 100) — исторические суммы сохраняют те же копейки).
Кратко: в БД и расчётах — BIGINT копейки (*_cents); в формах/JSON UI — рубли (часто с step=0.01); T‑Bank Init/выплаты — копейки без лишнего × 100 на стыке с ledger.

1) Канон

  • В БД и во внутренних расчётах суммы — целые копейки (BIGINT / int в PHP).
  • Имена колонок: суффикс _cents (например price_cents, fee_amount_cents, summ_cents).
  • Исключение по имени (не по единице): tinkoff_payments.amount, tinkoff_payouts.* — уже копейки, без rename.
  • Рубли с точкой/запятой — только на границе UI и внешних API (Robokassa, ЮKassa).
  • Не использовать float/double для хранения; не плодить локальные * 100 / / 100 вне Money.

3) Граница HTTP / UI

  • Формы и JSON админки принимают/отдают рубли (часто step="0.01").
  • Контроллер/Request валидирует рубли; запись в БД — через Money::toCents / toCentsOrFail.
  • Чтение для UI — Money::fromCents / динамический атрибут price, amount, fee_amount в рублях.
  • Resolvers оплаты (UserPriceMonthlyFeePaymentResolver, UserLessonPackageFeePaymentResolver) возвращают amount_cents + out_sum (строка рублей для Robokassa).

4) Округление

Математическое до копейки: по 3-му знаку дробной части рубля (0–4 вниз, 5–9 вверх). Реализация: Money::toCents / Money::normalizeRubString (PaymentOutSumNormalizer — тонкая обёртка).
  • 10,005 → 10,01 (1001 коп.)
  • 10,004 → 10,00 (1000 коп.)

5) Скидки %

UI персональной скидки ученика — admin-users §2.6, анонс — /doc. Расчёт в App\Support\Money и App\Services\Pricing\UserPercentDiscount.

Вариант А:

  1. скидка_cents = Money::discountCents(price_cents, percent) — round(price × % / 100)
  2. к_оплате = price_cents − скидка_cents (Money::payableAfterDiscountCents)

6) Отображение

  • Money::formatRub — целые без копеек; ,xx только если копейки ≠ 0 (публичная оплата ULP, DataTables preset money в kids-datatable.js).
  • Money::formatRubFixed — всегда два знака (сверки/выплаты; TinkoffMoney::rub делегирует сюда).
  • Money::fromCents — "1234.56" для провайдеров.

7) Оплаты и отчёты

  • Источник суммы месяца: users_prices.price_cents.
  • Источник суммы абонемента: user_lesson_packages.fee_amount_cents.
  • Ledger: payables.amount_cents → payment_intents.out_sum_cents → webhook → payments.summ_cents.
  • T‑Bank Init получает копейки напрямую из amount_cents (без повторного × 100 из рублей).
  • Отчёт «Платежи»: комиссии и нетто считаются от payments.summ_cents (не summ × 100 — иначе двойное умножение после миграции).
  • Отчёт «Задолженности»: суммы из price_cents / amount_cents, в UI — рубли.
В DataTables/JSON отчётов ключи колонок часто остаются summ, out_sum, amount, price (рубли для UI). В SQL/моделях — только *_cents.

8) API helper
